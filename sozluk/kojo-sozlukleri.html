Why the sizes differ — three levels of localization

Level 1

The interface

Menus, buttons, messages. A Bundle_xx.properties file per language. Every supported language reaches this level; it is not in these dictionaries.

Level 2

The vocabulary

The turtle commands, colours and types a child actually writes. This is what the dictionaries capture. Swedish and German stop here.

Level 3

The samples

Example programs rewritten in the language. Turkish has 82; German six, Spanish two, Dutch one; the other five, none yet.

Turkish only

The keywords

A patched Scala compiler so val→dez, if→eğer, def→tanım. No other language does this — hence Turkish is far larger.

Extracted from the litan/kojo repository and its Turkish fork bulent2k2/kojo (Koco): the patched compiler, lite/i18n/*Init.scala, lite/i18n/tr/, the level2_xx.properties files, and the parallel sample programs. Each dictionary is searchable in both directions and folds diacritics, so cizim finds çizim, weiss finds weiß, and zolw finds żółw. Every language with an xInit.scala is here. Two more — French and Esperanto — localize the interface (level 1) but not yet the vocabulary; when an frInit.scala or eoInit.scala appears, they join the shelf.
